# Working on Digital Live Zoo

Welcome. A short map of the project and the few things that move on their own.

## Layout
- `index.html` — the whole home page (Main Stage, filters, cam grid, wall). Plain HTML/CSS/JS, no build step.
- `catalog.json` — the cam list. Format is in `README.md`.
- `activity.json` — "how worth watching is each cam right now", written by `tools/activity.py`.
- `live/`, `animals/`, `places/`, `habitats/`, `sitemap.xml`, `sitemaps/`, `robots.txt`, `slugs.json` — generated by `tools/build_pages.py` from `catalog.json` and `data/`. Don't edit them by hand; edit `data/cams.json` / `data/hubs.json` or the builder instead.
- `assets/` — CSS/JS for the generated pages.
- `tools/` — Python scripts: `activity.py` (cam scoring), `build_pages.py` + `taxonomy.py` (cam pages), `mfk.py` (Made for Kids check).
- `.github/workflows/` — `activity.yml`, `pages.yml`, `mfk.yml`.

## Things that push to `main` without you
| What | How often | Touches |
| --- | --- | --- |
| `activity.yml` (github-actions bot) | meant to run twice an hour (see `STATUS.md`) | `activity.json` |
| `pages.yml` (github-actions bot) | when the catalog or `data/` changes, and daily | generated pages, sitemaps |
| `mfk.yml` (github-actions bot) | daily, needs `YT_API_KEY` secret | `mfk.json` |
| Claude routine on Zhan's Mac | daily | `catalog.json` |

So: `git pull --rebase` before you push, and prefer a branch + pull request for anything bigger than a small fix. GitHub Pages deploys `main` straight to https://digitallivezoo.com within about a minute.

## Run it locally
```sh
python3 -m http.server 8000      # then open http://localhost:8000
```
Live video needs a normal browser (YouTube's player). Add `?adpreview` to the URL to see the ad slot with a sample ad.

Cam scoring, one run (about 40 s; downloads a ~90 MB image model the first time):
```sh
pip install pillow numpy onnxruntime
mkdir -p .model && curl -sSfL -o .model/clip_vision.onnx \
  https://huggingface.co/Xenova/clip-vit-base-patch32/resolve/main/onnx/vision_model_quantized.onnx
python3 tools/activity.py catalog.json /tmp/activity.json .state .model/clip_vision.onnx
```
`.state/` and `.model/` are git-ignored. Movement and viewer spikes need a few runs of history before they kick in.

Cam pages:
```sh
python3 tools/build_pages.py
```
